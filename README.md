# Интернет-магазин

Проект интернет-магазина на Django, который разрабатывается в рамках курса.

## Структура проекта

- `internet_shop/` — основная конфигурация проекта
- `catalog/` — приложение для управления каталогом товаров

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python3 -m venv venv`
3. Активируйте окружение: `source venv/bin/activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Выполните миграции: `python manage.py migrate`
6. Запустите сервер: `python manage.py runserver`

## Ветки

- `main` — основная ветка (продакшн)
- `develop` — ветка разработки
- `feature/*` — ветки для новых функций
